# LazioEU — правила работы с репозиторием

Сайт консалтинга LazioEU (прямые гранты ЕС для компаний в Италии).
Живой сайт: https://ayanamiraaaay.github.io/italylawyer/ (GitHub Pages, «Deploy from a branch»: main, / root).
Репозиторий: github.com/ayanamiraaaay/italylawyer (с 12.11.2026). Старая копия в ayanamiraaaay/eu больше не основная — правки вносить только сюда.

## Деплой — автоматический
- Любая доработка сайта: правим файлы → `git commit` → `git push origin main`. GitHub Pages сам обновляет сайт за 1–2 минуты. Владелец проекта (Юра) просил делать это **автоматически, без отдельного вопроса**, для обычных правок.
- Спрашивать перед пушем, только если правка необратима или рискованна: удаление страниц, смена домена, крупная переделка структуры.
- Перед пушем: проверить страницы в браузере (Playwright, десктоп 1440 и телефон 390), без горизонтальной прокрутки, без ошибок в консоли.
- Сборки нет: чистый HTML/CSS/JS. Не добавлять npm-зависимости и сборщики без согласования.

## Структура
- Сайт многостраничный (с 13.11.2026, по просьбе Юры: главная была слишком длинной на телефоне). Пары IT / EN:
  - главная `index.html` / `en/index.html`
  - `chi-siamo.html` / `en/about.html` — кто мы + для кого
  - `servizi.html` / `en/services.html` — услуги подробно + цены и гарантии (`#prezzi` / `#pricing`)
  - `bandi.html` / `en/grants.html` — каталог программ
  - `verifica.html` / `en/check.html` — тест из 5 вопросов
  - `faq.html` / `en/faq.html` — FAQ (здесь JSON-LD FAQPage)
  - `contatti.html` / `en/contact.html` — форма (на мобильном форма идёт первой; нижней кнопки mcta на этой странице нет)
  - `privacy.html` / `en/privacy.html`
- Шапка и футер одинаковые на всех страницах (меню: Chi siamo · Servizi e prezzi · Bandi · FAQ · Contatti). Меняешь меню — меняй на всех 16 страницах.
- Каждая внутренняя страница: `.page-hero` (крошки, h1, lead) → содержимое → блок `.next` (призыв: проверка + тест). Ссылки «Fa per la mia impresa?» и результат теста ведут на страницу контактов с `?p=Программа` — форма подставляет её сама.
- `assets/site.css`, `assets/site.js`, `assets/favicon.svg`; `404.html` (использует `<base href="/italylawyer/">` — поменять при подключении своего домена); `.nojekyll`
- Любую правку текста вносить в IT и EN версии одновременно.
- Русская версия существует только как рабочая копия на холсте Design, на сайт не идёт.

## SEO и превью (сделано 12.11.2026)
- В `<head>` каждой страницы: canonical, hreflang it/en/x-default, Open Graph + twitter:card — все с абсолютным адресом `https://ayanamiraaaay.github.io/italylawyer/`. **При подключении своего домена заменить этот адрес везде** (16 страниц, sitemap.xml, robots.txt, JSON-LD, 404 `<base>`).
- Картинки превью: `assets/og-it.jpg`, `assets/og-en.jpg` (1200×630, ≤ 100 КБ). Иконки: `assets/apple-touch-icon.png`, `assets/icon-192.png`, `assets/icon-512.png`; `manifest.webmanifest`.
- JSON-LD: ProfessionalService на главных, FAQPage на faq.html / en/faq.html. FAQPage обязан совпадать с видимыми вопросами FAQ — при правке FAQ обновлять и его.
- `sitemap.xml` (с hreflang), `robots.txt`. Пока сайт на github.io, robots.txt не в корне домена и поисковиками не читается — заработает со своим доменом.

## Дизайн-приёмы
- Стиль v3 (13.11.2026): по просьбе Юры «не по-дедовски», референс — сайт «Чистый путь» (проект hayos, НЕ трогать сам репозиторий). Взяли приёмы, не копию: белая полупрозрачная шапка с меню-«таблетками», крупные плотные заголовки, карточки 18px с мягкой тенью, иконки в мягких квадратах, шаги-номера с линией, галочки в квадратиках, тёмно-синий итоговый блок `.next`, полноэкранное мобильное меню (`.nav.open` + кнопка `.nav-cta`).
- Своя изюминка — **римская арка (Lazio)**: фото с аркой сверху (`border-radius:50% 50% … / 150px …`), золотой «замковый камень» над фото (`.frame-hero::after`, `.frame-about::after`), мягкая арка в фоне hero, контурные арки в `.next` и `.side-cta`, знак-арка в логотипе (`svg.mark`) и favicon. Не перегружать: без точечных узоров и смещённых подложек.
- Кнопки: основная — тёмно-синяя, на тёмном фоне — янтарная. Выделение в h1 главной — `<em>` (янтарный маркер).
- Декор-арки никогда не заходят на текст: в `.next` на телефоне скрыты, в `.page-hero` показываются только от 1100px.
- Шапка с backdrop-filter: при открытом меню фильтр снимается (`body.menu-open`), иначе fixed-меню получает нулевую высоту.
- Фото на сайте: firma (hero), consulente (Chi siamo), consulenza (Come funziona, рамка .frame-wide), roma (Contatti, figure.city с подписью), progetti-green (hero каталога, .ph-grid). Источники/лицензии фото от Юры — подтвердить до запуска.
- Иконки: линейные SVG (`.ico`, stroke), набор в `.svc-ico` и `.prog-ico`.
- Блок «Verifica rapida / Quick check» (5 вопросов, `#quiz` в site.js): тексты результата — в словаре T внутри site.js (IT/EN), строятся через textContent. Это ориентир, не оценка — дисклеймер обязателен.

## Безопасность
- CSP в `<meta>` на каждой странице: никаких inline-скриптов и inline-стилей (`style="..."`), только классы из `site.css` и код в `site.js`.
- Без сторонних скриптов, cookie и аналитики. Если появится аналитика → нужен cookie-баннер по правилам Garante.
- Шрифты — Bunny Fonts (ЕС), не Google Fonts.
- Форма: открывает почтовую программу (mailto), на сайте данные не хранятся.

## Контент — правила
- Стандарт каждой страницы: 10 вопросов клиента (документ standard-10-voprosov в проекте Claude).
- Никаких выдуманных цифр, отзывов, кейсов, цен, названий конкурсов и дедлайнов. Нет данных — блок не показываем (заглушки только в макетах, не на сайте).
- Не обещать одобрение гранта. Не называть себя avvocati / studio legale. Не использовать флаг/эмблему ЕС.
- Стиль: аккуратно, строго, информативно, современно, для массового взрослого посетителя. Не «огромный красивый лендинг»: светлые секции; тёмные только футер, итоговый блок `.next` и боковая карточка каталога, заголовки h1 44px / h2 34px, отступы секций 72px, база текста 18px, высокий контраст, без капслока и жаргона, кнопки ≥ 44px, без наложений и «плавающих» карточек.
- **Мобильная версия — приоритет** (основная аудитория с телефона). На ≤640px: фото первого экрана сверху баннером 16:9, кнопки во всю ширину, шапка 60px, факты 2×2, шаги «номер слева», цены карточками, «Для кого» простым списком, портрет 4:3. Нижняя кнопка «Verifica gratuita» появляется после первого экрана и прячется у формы. Проверять на 320/360/390/414/768 без горизонтальной прокрутки.
- Главная (с 13.11.2026, ~9 экранов на телефоне — «вся база», но кратко): первый экран → ключевые факты → Chi siamo кратко (`#home-about`) → 3 услуги (`#servizi`) → Почему прямые фонды + «Fa per te se sei…» + чипы программ (`#fondi`) → Come funziona → Цены и гарантии кратко (`#prezzi-breve`) → 3 вопроса FAQ (`#faq-breve`) → блок `.next`. Каждый блок заканчивается ссылкой `.more` на свою страницу. Тексты блоков = тексты внутренних страниц (при правке менять в обоих местах). Больше блоков на главную не добавлять.
- Фото: только свободные лицензии (Unsplash/Pexels) или фото клиента. Стоковых людей НЕ подписывать как команду LazioEU. Хранить в `assets/img/`, формат WebP/JPEG ≤ 200 КБ, с width/height и alt.

## До публичного запуска (сейчас стоит noindex)
Нужно от клиента: P.IVA и юр. данные (обязательно в футере), телефон/WhatsApp/адрес/часы, цены, кейсы с согласием, команда, срок ответа (на сайте 48 ч — подтвердить), почта на своём домене.
После этого: убрать `noindex` со всех страниц, добавить canonical/hreflang с полным доменом, sitemap.xml.
